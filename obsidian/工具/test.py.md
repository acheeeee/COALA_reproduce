## 這是什麼

**我的實驗沙盒。** 不確定某個函數的用法或寫法時，在這裡試寫看看。

- 不被任何檔案引用
- 內容會隨時被覆寫，**沒有保存價值**
- 跑過的東西：各種資料集的讀取測試、API 用法試驗

> [!warning] 建議改名
> `test.py` / `test_*.py` 是 **pytest 的慣例檔名**。之後若要寫真正的單元測試會撞名（pytest 會自動把它當測試檔收集）。
>
> ```bash
> mv src/test.py src/scratch.py
> ```
> 並加進 `.gitignore`（沙盒檔不需要進版本控制）。

## 在沙盒裡試東西的好習慣

> [!tip] 用小一點的假資料，而且先猜答案
> ```python
> import torch
> # 用 2 個 frame、每個 3 維，方便肉眼看
> x = torch.arange(24).reshape(1, 8, 3)
> print(x)
> print(x.reshape(1, 4, 6))     # 先猜這會長什麼樣，再印出來對答案
> ```
> 猜錯就想為什麼。這樣練一小時比看三小時教學有效。
>
> 真實尺寸 `(4, 1500, 1280)` 印出來看不懂，`(1, 8, 3)` 一眼就看得出 reshape 做了什麼。
