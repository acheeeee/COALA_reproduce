## 模型層

### [[modules.py]]（9）

| 名稱 | 種類 | 功能 |
|---|---|---|
| [[AudioAdapter]] | 類別 | 把 Whisper encoder 的輸出（1280 維、1500 步）接到 LM 的 embedding 空間（576 維），同時把時間長度縮短 `stack` 倍。 |
| [[CTCHead]] | 類別 | 把 adapter 的輸出投影到 29 個 CTC 類別（blank + 28 字元）。 |
| [[AudioAdapter.__init__()]] | 方法 | 建 `Linear(1280·stack, 576)` |
| [[AudioAdapter.forward()]] | 方法 | frame stacking（相鄰 `stack` 個向量接成一個長向量）+ Linear 投影。 |
| [[CTCHead.__init__()]] | 方法 | 建 `Linear(576, 29)` |
| [[CTCHead.forward()]] | 方法 | `(B, L, 576)` → [[ctc_logits]] `(B, L, 29)` |
| [[compute_ctc_loss()]] | 函式 | 包裝 `F.ctc_loss`，處理好維度順序、log 機率、輸入長度。 |
| [[ctc_compress()]] | 函式 | 用 CTC 的預測挑出「有意義的位置」—— 去掉 blank 和連續重複，只留這些位置的 576 維向量給 LM。 |
| [[modules.main()]] | main | 用隨機資料檢查 adapter / CTC head 的 shape、參數量，以及 CTC loss 的量級。 |

### [[losses.py]]（6）

| 名稱 | 種類 | 功能 |
|---|---|---|
| [[bias_loss()]] | 函式 | baseline 的 Bias-Loss = disc loss + 輔助 log loss（Huang & Wang 2025 Eq. 2），論文實驗 B 的對照組。 |
| [[check()]] | 函式 | 測試小工具 —— 比對算出來的 loss 和手算答案，差距 < 1e-5 就印 ✅。 |
| [[disc_loss()]] | 函式 | 論文 Eq. 3 的 discriminative loss（baseline）—— 對**全部** K 個候選做一次 softmax，取正樣本的平均負 log 機率。 |
| [[dpd_loss()]] | 函式 | 論文 Eq. 5–7 的 DPD-Loss —— 每個 entity 各自做一個二元分類（在 / 不在），正負樣本完全解耦。 |
| [[mpd_loss()]] | 函式 | 論文 Eq. 4 的 MPD-Loss —— 每個正樣本**各自**只和 E⁻ 做 softmax，正樣本之間不再互搶。 |
| [[losses.main()]] | main | 用論文圖 2(b) 的 5 個手寫分數，驗證四個 loss 的數值、穩定性、梯度方向。**完全不需要模型。** |
